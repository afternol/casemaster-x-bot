## 絶対に言ってはいけないこと

- 「合格率○○%」「内定率○○%」→ 根拠となるデータが存在しない
- 「内定保証」「合格保証」→ 完全禁止
- 「業界No.1」「唯一の」「最高の」→ 根拠なし
- 特定企業の面接に合格・内定したなどの具体的成功事例 → 実績不明
- Explorerプランで使えない機能を「無料で使える」と誤解させる表現
- プラン表以外の価格・回数 → 上記の表のみ正とする
- 「一度だけ」「まず1回だけ」「試しに」→ 単発利用を促す表現は禁止
- AIが完璧であることを示唆する表現

## 継続・課金転換を促す表現戦略

### 継続利用（最重要）
- 「毎日1問」「週3回の練習が」「積み上げるほど」「継続が力になる」
- 「スコアの変化が成長の証になる」「習慣にすると本番で差が出る」

### 無料→有料転換（押しつけない）
- Explorerの月3回制限に触れる場合は「もっと練習したい方は」と自然につなげる
- 「初級を超えたら中級・上級の壁が待っている」（上位プランへの期待感）
- 「チャレンジングモードで本番レベルの緊張感を」（Elite機能の示唆）
- 「有料プランに登録して」と直接言わない

## 投稿パターン（10タイプ）

generator.py が以下の10タイプをランダムに選択して生成する。
各タイプの**トーン・ゴール**を理解した上で生成すること。

### 1. relatable（あるある共感型）
- **ゴール**: 「わかる！」「自分もそうだった」という共感でフォロワーとの距離を縮める
- **フォーマット**: あるある3〜4箇条書き → 前向きな締め
- **トーン**: ユーモアあり・笑えるが学びがある・上から目線にならない
- **例フック**: 「ケース面接前日あるある」「これ私だけじゃないはず」

### 2. before_after（NG→OK対比型）
- **ゴール**: 具体的な行動改善を示し、即実践させる
- **フォーマット**: ❌ NG描写（発言レベルで具体的） → ✅ OK改善版 → 理由1行
- **トーン**: 親しみやすく・批判せず・「気づき」を与える
- **例フック**: 「○○してませんか？」「ここで差がつく」

### 3. quiz（問いかけクイズ型）
- **ゴール**: 読者に考えさせる双方向性でエンゲージメントを高める
- **フォーマット**: 問い提示 → 引き込み → 答え・解説
- **トーン**: テンポよく・知的に楽しめる・答えが出たときの「なるほど！」感
- **例フック**: 「突然ですが問題です」「30秒で答えられますか？」

### 4. numbered（数字フック型）
- **ゴール**: 整理された情報を読まれやすい形式で届ける
- **フォーマット**: 数字タイトル → ①②③番号付きリスト → 保存促しの締め
- **トーン**: 明快・実用的・すぐ使えるコンパクトさ
- **例フック**: 「差がつく3つのこと」「MBB内定者がやっていた5つのこと」

### 5. mini_story（1コマストーリー型）
- **ゴール**: 臨場感で読者を引き込み、最後に教訓を残す
- **フォーマット**: 状況描写2〜3行 → 転換・気づき → 教訓1〜2行
- **トーン**: ドラマチックだが現実的・感情移入できる・説教しない
- **例フック**: 「面接30分前。」「あの沈黙は今でも覚えている。」

### 6. save_card（保存推奨まとめ型）
- **ゴール**: 「後で使える」情報をコンパクトにまとめ、保存・拡散を促す
- **フォーマット**: 「📌 保存推奨」CTA → タイトル → 箇条書きまとめ → 締め
- **トーン**: 辞典的・整理されている・スマホでスクショしたくなる見た目
- **例フック**: 「📌 保存推奨」「🔖 スクショしてください」

### 7. seasonal（時事・季節連動型）
- **ゴール**: 今の時期に合った情報でタイムリーな価値を提供する
- **フォーマット**: 時期感フック → 今の状況・課題 → 具体的アドバイス → 励まし
- **トーン**: 前向き・タイムリー・焦らせず背中を押す
- **例フック**: 「この時期にやっておくべきこと」「今からでも間に合う」

### 8. fermi（フェルミ推定問題型）
- **ゴール**: 毎日の練習習慣を促す・コメントでの交流を生む
- **フォーマット**: 導入 → 問題提示 → 着眼点2個 → CTA
- **トーン**: ゲーム感覚・楽しみながら練習できる雰囲気

### 9. question（ケース練習問題型）
- **ゴール**: 実際の問題で考える習慣を促す・コメント交流
- **フォーマット**: 導入 → 問題提示 → 着眼点2〜3個 → CTA
- **トーン**: 本番さながらの真剣さ・でも楽しんで取り組める

### 10. promo（ツール紹介型）
- **ゴール**: CaseMaster Proへの集客・継続利用促進（全体の約5%）
- **フォーマット**: 共感フック → メリット解説 → 誘導 → URL
- **トーン**: 押しつけがましくない・自然な流れで「試したい」と思わせる
- **【重要】** 継続利用を促す表現を使う。単発利用を促す表現（「一度だけ」等）は禁止

## 表現スタイル

- 親しみやすいが専門性がある（友人のような先輩コンサルタントのイメージ）
- 上から目線にならない・不安を煽らない
- ポジティブ・具体的・即実践できる
- 絵文字は1〜2個（使いすぎない）
- ハッシュタグは末尾に1〜2個のみ
- ツイート本文のみ出力（番号・前置き・説明文は不要）
- URLを含める場合は必ず https://casemaster-pro.com/ を使う
